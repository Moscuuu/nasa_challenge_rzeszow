> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extend the analysis→GUI hand-off to contract v0.3 (per-site feature scores, per-site top cells, validation bboxes), regenerate `out/` locally and commit it.

**Architecture:** Small changes to the existing numpy pipeline in `pipeline/`. Pure helpers get pytest tests on synthetic arrays; the full run is verified by inspecting `out/`. Work happens on branch `contract-v0.3` (already created from `main`, empty) and ends in a PR for the analysis team.

**Spec:** `docs/superpowers/specs/2026-11-14-gui-mirror-design.md` §10 (on branch `gui-design`), contract `docs/contracts/analysis-to-gui/CONTRACT.md`.

## Global Constraints

- `CONTRACT_VERSION = "0.3"`; every shape change raises the contract version (CONTRACT.md §10).
- Scores 0–1, rounded to 3 decimals; missing data is `null`, never 0.
- Coordinates east-positive, −180…180; GeoJSON `[lon, lat]`.
- User-facing labels in English.
- Earth Engine: the default `ee.Initialize()` fails on this machine; the service account route (`scripts/ee_init.py` on branch `combine-score`, key in `~/.config/analog-finder/ee-key.json`) works. Never print, copy or commit the key.
- If any pipeline step fails (download, EE auth, missing file), stop and report the exact error. Do not work around it with fake data.

## Review Focus

1. A site whose best cells are all outside the global top 2000 (e.g. `hellas_rim`) must still have ≥ `TOP_N_SITE` cells in `cells_top` → test in Task 2.
2. A cell with `ground_ice` or `temperature` NaN for one site → that site's entry has `null` score and the feature is left out of `strengths`/`breaks_down`, not scored as 0 → test in Task 3.
3. `experiment_window.py` and `export.py` must select the same cells, or windows silently go missing → both import one function (Task 2), test asserts determinism.
4. `cells_top_0-1m.geojson` must stay ≤ ~3 MB → size check in Task 5.
5. A validation check with zero cells in its box keeps `median_percentile: null` and still carries its `bbox` → test in Task 1.

**Interfaces:**
- Produces: `select_top(best: np.ndarray, overall: np.ndarray, top_n_global: int = 2000, top_n_site: int = 300) -> np.ndarray` — int indices, unique, ordered by `best` descending (NaN last, stable). `overall` shape `(n_sites, n_cells)`.
